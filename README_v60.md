# v60 株価表示の修正

## 原因
従来は日足3か月データの `meta.regularMarketPrice` を「現在株価」として表示していた。日足は取引時間中に最新約定値と一致するとは限らず、前営業日の終値などを現在値と誤認しうる。詳細評価の株価キャッシュも60秒保持していた。

## 変更
- 既存の日足取得後に当日1分足 (`/api/chart?interval=1m&range=1d`) を取得し、当日JSTの有効な最新約定値を優先。
- 1分足がない場合は日足の参考値と明記し、リアルタイムと表示しない。
- 詳細評価のキャッシュは当日1分足取得時のみ15秒。
- 詳細評価に価格データの種類と日本時間の時刻を表示。
- 予測エンジン、Googleカレンダー、Supabase履歴処理、バックエンドのコードは変更しない。

## 制限
市場データ提供元の配信遅延や取得失敗により、証券会社の価格との一致は保証できない。1分足取得の追加で通信時間が増える場合がある。実環境の銘柄ごとの検証は未実施。

## 反映
公開GitHub Pagesリポジトリ `stock_app` の `index.html` を上書き。Render側は変更不要。
