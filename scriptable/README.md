# Scriptable ウィジェットの導入

Scriptable は、Webサイトから任意のスクリプトを自動インストールする URL scheme を提供していません。これは iOS / Scriptable の安全上の制約です。

初回だけ、iPhone の日本株チェッカーで **❓ヘルプ → iPhoneウィジェット設定** を開き、案内どおりに `stock.js` をScriptableへ追加して、スクリプト名を **日本株チェッカー** として保存してください。ソースコード・同期キーともに編集や手入力は不要です。その後は同ページの **お気に入りを同期してScriptableを開く** を押すだけで、短時間だけ有効なペアリングコードを渡して同期を開始できます。ホーム画面で Scriptable ウィジェットを追加し、このスクリプトを選んでください。

長期利用する同期トークンは URL・クリップボード・ログには出ません。URL に含まれるのは一回限り・5 分で失効するペアリングコードだけです。既に `CONFIG.widgetToken` を設定済みの利用者は、そのまま同期を継続できます。
